# SVA Matrix Squad — Testing

## Verification Pipeline

1. Syntax Check
2. Project Detection
3. Test Planning
4. Test Execution
5. Failure Analysis
6. Repair Proposal
7. Controlled Repair
8. Retest
9. Verification
10. Report

## Required Evidence

Every repair must produce:

- Original failure
- Proposed fix
- Applied change
- Retest result
- Verification result

## Quality Gate

A task is successful only when the relevant tests pass after the repair.
