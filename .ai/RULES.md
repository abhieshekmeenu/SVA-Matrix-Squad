# SVA Matrix Squad — Rules

1. Do not break existing working features.
2. Do not overwrite user projects unnecessarily.
3. Make backups before risky modifications.
4. Keep repairs project-scoped.
5. Test every important code change.
6. Retest after every repair.
7. Never claim success without verification.
8. AI repair proposals must be validated before execution.
9. Preserve existing APIs and interfaces unless intentionally changed.
10. Keep code readable and maintainable.
