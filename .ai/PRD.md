# SVA Matrix Squad — Product Requirements

## Purpose
SVA Matrix Squad is an AI-powered assistant for Termux/Linux users.

## Core Features
- Ask AI
- General Questions
- Linux/Termux Explanation
- Code Assistant
- Cybersecurity Learning
- Task Agent
- Multi-provider AI support
- Chat history and memory
- Universal project testing and verification

## Universal Testing Goal
The Task Agent should be able to inspect a project, detect its technology, plan tests, run tests, analyze failures, propose repairs, retest, verify results, and generate a report.

## Safety
AI-generated repairs must remain controlled and project-scoped.
